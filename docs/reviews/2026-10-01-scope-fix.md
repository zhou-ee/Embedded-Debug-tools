# V1.2.29 示波修复与复测记录

修复及复测时间：2026-09-30 至 2026-10-01。对应 [V1.2.28 审查报告](2026-09-30-scope-audit.md)。

“坑洼”的已确认主因是前端 TornSampleFilter 误改正常浮点值。正常采样 `16.18034 → 20 → 16.18034` 原来会被削成 `16.125`；真机负值也曾被重构为正值。V1.2.29 移除了采样摄取与 CSV 导出的自动重构。历史算法仅留作离线对照，不进入测量数据路径。

## 已完成的修复

- **采样与导出保持原始解码值**：统一使用 `ScopeSamples` 存储，CSV 通过 `ScopeCsv` 按实际纳秒时间戳合并通道。缺失单元格留空，不做最近邻填补。
- **缺样与空档可见**：引擎对失败目标显式发送空字节；前端同时识别省略、空值和长度不符，保存 NaN 缺样点并计数。超过三个目标采样周期的间隔标记为空档。绘图先分段，再在各段内保留入口、极值和出口；游标不跨缺口吸附。
- **共享会话按归属清理**：OpenOCD 用实际子进程归属判断共享连接，覆盖 `attachOnly=false` 但复用已有服务的情况。退出、断开与换连接共用清理路径，只释放本会话配置且仍匹配原配置的 DWT 槽位；外部占用及被外部改写的槽位保留。共享目标暂停时不自动恢复运行。
- **通道重新定位**：ELF 重载、重连和恢复采样时重解析表达式通道。指针成员使用现场读取的指针值，支持嵌套指针和数组；重定位会清理相关旧序列。无法定位的通道暂停下发并显示“待定位”。固定地址及 SVD 寄存器通道保留地址绑定，兼容旧持久化配置。
- **相关修正**：相同目标和频率重复下发不再触发预热丢弃；目标改变时清空引擎旧缓冲。OpenOCD 整批失败保留缺样帧并避让 50ms，Tcl 传输损坏触发断线恢复。带宽预警改为协议要求的地址/长度二元组，并标明估算占用。

## 验证结果

自动回归：`cargo test --workspace --locked --offline` 共 **58 项通过**；`plugin/gradlew.bat test --offline --console=plain` 共 **145 项通过**。新增覆盖正常波峰和符号位保持、缺样导出、同一 M4 桶内的缺口、游标缺口、ELF 重定位、嵌套指针、固定寄存器，以及 DWT 分配/归属/退出行为。安装包中的摄取和导出类也已检查，不含 TornSampleFilter 引用。

修复前采集的 **83,185 帧**使用当前编译的 `ScopeSamples` 和 `ScopeCsv` 回放，存储及 CSV 数值改写均为 **0**，原先被削掉的波峰和被改符号的负值得到保留。

协议故障注入使用实际 release Agent：一块持续失败时，40 帧均包含该通道的显式缺样；整批失败时保留了 18 帧、36 个通道缺样。模拟四个外部 DWT 槽位和外部暂停状态后退出，清理写入为 0，没有发送 `resume`。
